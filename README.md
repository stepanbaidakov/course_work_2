# Проект Интеграция c hh.ru
## Описание:
Проект интеграции, который получает информацию о вакансиях с платформы
hh.ru в России, сохраняет ее в файл и позволяет удобно работать с ней: добавлять, фильтровать, удалять.
## Установка
1. Клонируйте репозиторий:
`git clone https://github.com/stepanbaidakov/course_work_2.git`
## Использование:
1. Откройте и запустите файл `main.py`
## Документация:
### Класс `HhRu`
Класс для взаимодействия с api
* метод `connect` для подключения к api
* метод  `get_vacancies` для получения вакансий по запросу
### Класс `Vacancy`
Класс для создания объектов вакансий
* метод `cast_to_object`: переобразует полученные вакансии
в объекты класса в выбранными атрибутами
* метод `to_json` переобразует экземпляры обратно в json
* методы сравнения `__gt__, __lt__` вакансий по зарплатам
### Класс `JSONSaver`
Класс для работы с файлом
* метод `add_vacancies_to_file` для добавления вакансий в файл
* метод `get_vacancies_from_file` для получения вакансий из файла
* метод `delete_vacancies` удаляет весь файл с вакансиями
